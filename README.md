# KTV Room Rental & Food Ordering Management System

A standalone, offline Windows desktop application for managing KTV establishments, built with Python, CustomTkinter, and JSON storage.

## Features
- Room Management & Real-time Monitoring
- Room Sessions, Timers, Extensions & Overtime
- Food & Beverage Ordering & Cart Management
- Billing, Upfront/Checkout Payments & PDF Receipts
- Comprehensive Analytics & Matplotlib Graphs
- Manual Backup & Restore

## Running the Application
1. Activate virtual environment: `venv\Scripts\Activate.ps1`
2. Run main script: `python main.py`
