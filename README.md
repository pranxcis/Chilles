# Chilles KTV 

A standalone, offline Windows desktop application for managing KTV establishments, built with Python, CustomTkinter, and JSON storage.

## Features
- Room Management & Real-time Monitoring
- Room Sessions, Timers, Extensions & Overtime
- Food & Beverage Ordering & Cart Management
- Billing, Upfront/Checkout Payments & TXT Receipts
- Comprehensive Analytics & Matplotlib Graphs
- Manual Backup & Restore

## Running the Application

1. **Open the project folder** in VS Code.
2. **Open the integrated terminal** (`Ctrl + ``).
3. **Activate the virtual environment:**

   ```powershell
   venv\Scripts\Activate.ps1
   ```

4. **Install project dependencies** (first-time setup only):

   ```bash
   pip install -r requirements.txt
   ```

5. **Run the application:**

   ```bash
   python main.py
   ```

6. **Close the application** using its Exit or Close button when finished.
